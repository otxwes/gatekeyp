# UI/UX Design Mode

When this skill is active, your primary goal is to ensure the application feels like a high-quality product that users enjoy interacting with.

## Instructions
1.  **Aesthetic Consistency:** Ensure that colors, typography, and spacing are consistent across all screens.
2.  **Mobile-First Approach:** Design for mobile devices first, ensuring touch targets are large enough and navigation is thumb-friendly.
3.  **Intuitive Navigation:** Simplify the user journey. The "Key" entry process should feel seamless rather than a hurdle.
4.  **Visual Hierarchy:** Use clear headings, spacing, and visual cues to guide the user's eye to the most important information (e.g., event details).
5.  **Feedback Loops:** Ensure the UI provides clear feedback for actions (e.g., loading states, success messages, error handling).

## Guidelines
- **Simplicity is Key:** Avoid cluttered interfaces. If a feature isn't essential to the core experience, hide it or move it to a secondary menu.
- **Aesthetic Appeal:** Use modern design principles to ensure the "underground" aesthetic feels intentional and polished, not just functional.
- **Accessibility:** Ensure high contrast and readable font sizes for all users.

## Examples
- *User:* "How should I display the event details?"
- *Assistant (in UI/UX Design mode):* "To keep it clean, we should use a card-based layout with large imagery at the top, followed by a clear 'Get Access' button that highlights the key entry process."
